# CAT-001: Rocky Engineering Asset Catalog

## Purpose and catalog contract

This is the canonical initial inventory of Rocky [Knowledge Assets](../glossary.md). It catalogs
identity, location, lifecycle state, and relationships; the linked asset remains canonical for its
content. Lifecycle meanings and authority are defined in [REF-001](../handbook/REF-001.md).

Catalog status describes the asset document, not a runtime product capability. A missing optional
series entry does not reserve an ID. Templates are reusable assets and contain placeholder fields
by design.

## Catalog maintenance

Add an entry when a new canonical top-level asset or series is introduced. Update an entry in the
same change as an asset lifecycle or location change. Review links automatically and metadata,
ownership, relationship direction, duplicates, and status claims manually. Historical accepted
ADRs remain indexed after supersession with their lifecycle state and reciprocal links.

No runtime registry, database, graph, crawler, or synchronization service is implied or selected.
The implemented [`rocky.knowledge_assets`](../../src/rocky/knowledge_assets/) package is a
persistence-free runtime domain and application boundary, not a catalog storage implementation.
