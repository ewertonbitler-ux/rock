# Release checklist

- [ ] The governing PRD release conditions and EPKG acceptance criteria are satisfied.
- [ ] Lint, type-check, tests, and link validation pass in the supported environment.
- [ ] Package REVIEW records exact results and unresolved environmental limitations.
- [ ] User-facing navigation and version metadata match the released behavior.
- [ ] Accepted ADRs are current, and any superseded decisions have reciprocal links.
- [ ] A maintainer inspected the final diff and approved the release through repository controls.
