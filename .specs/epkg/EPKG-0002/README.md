# EPKG-0002: Rocky architecture baseline and engineering asset catalog

This documentation-only package extends navigation and architecture knowledge for the framework
established by [PRD-001](../../../docs/prd/PRD-001.md), while preserving its prohibition on product
domain classes. It follows [ADR-001](../../../docs/adr/ADR-001.md),
[ADR-002](../../../docs/adr/ADR-002.md), and [ADR-003](../../../docs/adr/ADR-003.md).

Read package artifacts in this order:

1. [SPEC](SPEC.md) — normative BIT-465 scope and acceptance criteria.
2. [PROMPT](PROMPT.md) — provider-neutral execution guidance.
3. [TESTS](TESTS.md) — verification plan and exact commands.
4. [REVIEW](REVIEW.md) — factual completion evidence and deferrals.

Canonical terminology and lifecycle policy remain in the
[glossary](../../../docs/glossary.md) and [handbook](../../../docs/handbook/REF-001.md).
